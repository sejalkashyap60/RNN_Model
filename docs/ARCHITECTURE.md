# Architecture and data flow

`model/text.py` normalizes tokens, deterministically splits their ordered stream, and builds context/target pairs within each split. `model/rnn.py` owns initialization, forward intermediates, stable softmax, cross-entropy, and manual BPTT. `training/trainer.py` runs SGD and evaluates validation and test loss. `training/experiments.py` creates a fresh model and common vocabulary/split policy for each run. `training/experiment_history.py` stores compact local JSON summaries without corpus contents or parameter arrays. `model/checkpoint.py` stores model metadata as JSON and arrays as NPZ with pickle disabled at load. `app.py` presents training, prediction, visualization, Experiment Lab, and documentation in Streamlit. Prediction and visualization call the same `VanillaRNN.forward` implementation.

`training/data.py` is the shared deterministic split and sequence preparation path. `training/evaluation.py` computes held-out RNN metrics and the train-only bigram baseline. `ui/architecture.py` builds the pipeline, cell, and weight-shared unrolled views; `ui/charts.py` renders numerical heatmaps and bars; `ui/application.py` connects the eleven interactive pages. Experiment summaries link to per-run checkpoints containing NPZ weights and a last-gradient snapshot.
